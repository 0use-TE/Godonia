# Godonia

Avalonia UI inside Godot 4 (Vulkan / Skia).

> **AI-assisted codebase.** Stability is **not** guaranteed. Maintainers review changes; you still need to test.

Based on the original [Estragonia](https://github.com/MrJul/Estragonia) by **Julien Lebosquain** (MIT).

## What you need

Use the **custom Godonia Godot editor** from this repo (`godot/bin/`). New projects get the Avalonia template and restore **`Ouse.Godonia` 1.0.0** from the editor-local nupkg folder (`GodotSharp/Godonia/nupkg`), not from nuget.org.
